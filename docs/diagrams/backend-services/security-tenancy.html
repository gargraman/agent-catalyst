Backend Services · 09 · Security & multi-tenancy

One paved road in, no way around it

Every request crosses from untrusted to tenant-scoped through the auth guard; secrets decrypt in memory only; tool execution is exiled to an egress-restricted sandbox a caller can never reach directly.

DEFENCE IN DEPTH

Guard and RLS

The guard is the primary 403; RLS is the backstop — if a query ever forgets WHERE workspace_id, it returns zero rows, not another tenant's data. A CI isolation suite proves both hold.

WHY THE SANDBOX EXISTS

Injection ≠ exfiltration

Tool/MCP execution driven by model output is the weaponizable surface. gVisor isolation + deny-by-default egress means a prompt-injected agent can't become an SSRF or exfil primitive.

IMMEDIATE REVOCATION

The Redis deny-set

Claims are the authZ source of record (next-login), but a transient deny-set keyed by subject and token id fails closed now — one admin revoke-user cuts live sessions and caller tokens at once.
