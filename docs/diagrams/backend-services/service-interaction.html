Four thin callers, one runtime core

Playground, published invoke, eval, and channel all execute an agent through the same runtime.invoke() — so a drift report evaluates exactly the code the endpoint runs.

THE ONE IDEA

One code path

Playground, published, eval, and channel are four thin wrappers over one runtime.invoke(). If they diverged, a drift verdict would grade code the endpoint never runs.

LIBRARY, NOT SERVICE

Shared by api + worker

runtime/ has no FastAPI or HTTP import — it takes a RunContext, yields StreamEvents. That is what lets the eval worker and the HTTP endpoint share it.
